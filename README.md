# Wang Yeung — GitHub Pages migration

Static copy of https://www.wang-yeung.com/ with the original page layout and content. No Node.js build is required.

## Publish

1. Copy the contents of this folder to the root of your GitHub repository. Include `assets/` and `.nojekyll`.
2. Open repository Settings → Pages.
3. Select Deploy from a branch, your main branch, and / (root). Save.
4. GitHub will display the published URL when deployment completes.

Relative asset paths support both username.github.io and project repositories.

## Contact form

The enquiry form opens the visitor's email application. The visitor must send the email there. GitHub Pages has no server-side form processing. Telephone, email and WhatsApp links retain the reference site's contact details.

## Custom domain

Only add a CNAME file and change DNS after the GitHub Pages version is verified and you are ready to move the existing domain.
